# 예시 — all_total_vue 과제 (2026-10)

kstack이 나온 원래 과제의 실제 파일이다. 형식을 참고할 때만 본다(수치·경로는 그 과제 기준).

| 파일 | 무엇의 예시 | kstack에서 대응 |
|---|---|---|
| `criteria_mission_example.md` | 미션 원문 (C1~C5가 여기서 나옴) | `doc/criteria/mission.md` |
| `criteria_standard_example_excerpt.md` | 기준표 앞부분 (단원 표 → K1~K15) | `doc/criteria/standard.md` |
| `final-report/00_code_index_excerpt.md` | `[Px BEFORE/AFTER]` 주석 색인 | `/final-report index` |
| `final-report/01_problem_recognition.md` | Before 문제 지도·슬라이드 | `/final-report problem` |
| `final-report/03_step1_P1.md` | L3 단계 문서 ①~⑦ + 커밋 보고 7항목 | `/report-step` |
| `final-report/10_final_presentation.md` | 5분 발표, 미션 순서, 대본 | `/final-report present` |
| `final-report/12_tradeoffs_summary.md` | ✅/⚠️/(추정) 트레이드오프 | `/final-report tradeoffs` |
| `claude-config/original_*` | 일반화 전 원본 스킬·에이전트·구성 설명서 | `template/.claude/` |
