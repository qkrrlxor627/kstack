# /kstack-setup — 평가 가이드 → ID 체계

인자: `$ARGUMENTS`
- 첫 번째: 미션 파일 경로. 없으면 `.claude/kstack.json`의 `criteria.mission`.
- 두 번째: 기준표 파일 경로. 없으면 `criteria.standard`.

이 스킬이 만드는 `doc/criteria/ids.md`는 이후 `/improve`, `rubric-reviewer`, `/report-step`, `/final-report`가 모두 읽는 **유일한 ID 출처**다. 여기서 잘못 쪼개면 뒤가 전부 틀어지므로 사람 확인을 반드시 받는다.

## 절차
1. **입력 확인**
   - 미션·기준표 파일이 있는지 본다. 없으면 멈추고 `doc/criteria/README.md`를 안내한다.
   - 기준표 파일 이름이 기본값과 다르면 `kstack.json`의 `criteria`·`protected`와 `settings.json`의 `permissions.deny`를 실제 경로로 맞춘다. 보호 경로 셋은 항상 같아야 한다.
   - 두 파일을 끝까지 읽는다. 길면 나눠서 읽는다. 일부만 읽고 ID를 만들지 않는다.
2. **C ID (미션 = 최종 산출물이 갖춰야 할 것)**
   - 미션의 번호·항목 순서를 그대로 C1, C2 …로 쓴다. 하위 요소는 `C3-a`처럼 붙인다.
   - "선택", "필수", "캡처 필수" 같은 조건 문구를 그대로 옮긴다.
   - 발표 시간·분량 제약이 있으면 `kstack.json`의 `presentation.minutes`에 넣는다.
3. **K ID (기준표 = 판정할 때 쓰는 기술·개념 기준)**
   - 기준표의 단원·장·항목 번호를 그대로 K1, K2 …로 쓴다. 새로 묶거나 이름을 바꾸지 않는다.
   - 각 K마다 "충족 판단 방법"을 한 줄로 쓴다: 코드에서 무엇을 보면 충족인지(파일 패턴, 함수, 설정, 테스트).
   - 원문 쪽수·절 번호가 있으면 함께 적는다.
4. **충돌 표시**
   - 미션은 요구하지만 기준표에 없는 것(또는 그 반대)을 "충돌·공백" 절에 적는다. 임의로 메우지 않는다.
5. **ids.md 작성** — 아래 형식으로 `doc/criteria/ids.md`를 쓴다(`criteria.ids` 경로).
6. **설정 채우기** — 코드를 훑어 `kstack.json`의 다음 값을 제안한다. 확실하지 않은 값은 비워 두고 질문 목록에 넣는다.
   - `test.watch`: 소스·테스트 폴더 (예: `["src/", "tests/"]`)
   - `test.cmd`: 단위 테스트 명령
   - `bench.run_cmd`, `bench.health_cmd`: 측정 스크립트가 있으면. 없으면 비워 둔다(측정은 선택)
7. **사람 확인** — ids.md 요약(C 개수, K 개수, 충돌 목록)과 설정 제안, 질문을 출력하고 멈춘다.
   - 사용자가 확인하기 전에는 `/improve`로 넘어가지 않는다.
   - `doc/workClaude.md`의 변경 이력에 한 줄 추가한다.

## ids.md 형식
```markdown
# 평가 ID 체계 — <프로젝트>
> 출처: <미션 경로>, <기준표 경로> / 작성일: YYYY-MM-DD / 사람 확인: 미확인|확인(날짜)

## C ID — 미션
| ID | 항목 (원문 요약) | 조건 | 충족 판단 방법 |
|---|---|---|---|
| C1 | | 필수 | |
| C3-a | | | |

## K ID — 기준표
| ID | 단원 (원문 제목) | 핵심 기준 한 줄 | 충족 판단 방법 (코드에서 볼 것) | 원문 위치 |
|---|---|---|---|---|
| K1 | | | | p.N |

## 충돌·공백
- (미션에만 있음 / 기준표에만 있음 / 해석이 갈림)

## 제약
- 발표: N분 / 분량: / 마감:
```

## 규칙
- 미션·기준표 원본은 절대 수정하지 않는다(hook이 막는다).
- ID는 원문 순서와 번호를 따른다. 보기 좋게 재배치하지 않는다.
- 원문에 없는 기준을 추가하지 않는다. 필요해 보이면 "충돌·공백"에 적는다.
